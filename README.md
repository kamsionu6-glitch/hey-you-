# Hey, you ❤️

A small interactive website: intro, a few reasons, a mini quiz, a big question, and a confetti celebration.

## Tech
Plain HTML + CSS + JavaScript. No framework, no build step, no backend, no database, no API keys.
Fonts (Fraunces, DM Sans) load from Google Fonts.

- index.html: structure and text
- style.css: look, dark mode, animations
- script.js: screen changes, quiz, name personalisation, confetti

## Run on your computer
Double-click index.html. (Internet is only needed for the Google Fonts.)

## Publish free on GitHub Pages
1. Create a free account at https://github.com/signup
2. Create a new PUBLIC repository (for example: hey-you).
3. Click Add file > Upload files, drag in everything from this folder, then Commit changes.
4. Go to Settings > Pages. Source = Deploy from a branch, Branch = main, Folder = / (root), then Save.
5. Wait 1-3 minutes. Your link will be https://YOUR-USERNAME.github.io/hey-you/

## Update later
Open a file in your repository, click the pencil icon, edit, then Commit changes.
